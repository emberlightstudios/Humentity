# Humentity (MakeHuman inside Bevy)

## Current features
- Shape-able humans
- Auto-rigging
- Animation retargeting
- LOD
- Customizable equipment and body parts
- Customizable morph targets

## Future Plans
- Better shaders
- Compute shaders for faster realtime mesh shaping
